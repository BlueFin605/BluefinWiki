# Phase 7 AI Sidebar E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** automate all 4 still-owed manual-walkthrough exit-criteria items
for Phase 7 (create_page action apply, auto fetch_url tool loop, instruction
attach/lock/create, transcript auto-scroll) as Playwright specs. All four
are automatable with **zero production code changes** — the blocker
(Chrome's on-device Prompt API isn't available in Playwright's bundled
Chromium) has a clean test-side workaround already proven by this repo's own
jsdom test suite.

**Architecture:** Chrome's `LanguageModel` global is invoked as a bare
global in production code (`ai.ts:204-212`, `:604-629`), not behind Angular
DI. Every jsdom spec already mocks it identically: assign a plain object to
`globalThis.LanguageModel` before the code under test runs. That pattern
transfers directly to Playwright via `page.addInitScript()`, which runs
before Angular bootstraps on every navigation. This plan's Task 1 builds
that stub once as shared fixture infra; every other task consumes it.

**Tech Stack:** Playwright (`e2e/`), local Aspire dev stack.

### Task 1: `e2e/fixtures/ai.ts` — `LanguageModel` stub

**Files:**
- Create: `e2e/fixtures/ai.ts`

**Interfaces:**
- Produces: `installLanguageModelStub(page: Page, responses: string[]): Promise<void>` — queues raw JSON-string model responses, consumed in order by successive `session.prompt()` calls; the last response repeats once the queue is exhausted (so a test doesn't need to over-provision). Also exposes `getPromptCalls(page: Page): Promise<string[]>` to retrieve every prompt's first-argument text for assertions (needed by Task 3's "instruction content reached the model" check).
- Consumed by: Tasks 2, 3, 4, 5.

Response shape mirrors the app's own contract (`ai.ts:435-459` /
`promptModel`): a JSON string with `{message: string, action?: {...}}`.

- [ ] **Step 1: Read `frontend/src/app/features/ai/ai.spec.ts:34-42`** to
  copy the exact stub shape the jsdom tests already use (method names,
  `availability()` return value on the "available" path) before writing the
  fixture below — this plan's snippet is written from the investigation
  summary; confirm field names against that spec file directly.

- [ ] **Step 2: Write the fixture**

```ts
import type { Page } from '@playwright/test';

/**
 * Stubs Chrome's on-device Prompt API (`LanguageModel`), which isn't
 * available in Playwright's bundled Chromium (no Optimization Guide
 * component). Mirrors the exact `globalThis.LanguageModel = {...}` shape
 * every jsdom AI spec already uses (see ai.spec.ts) -- this is test-only
 * infra, no production code changes.
 */
export async function installLanguageModelStub(page: Page, responses: string[]): Promise<void> {
  await page.addInitScript((queuedResponses) => {
    (window as unknown as Record<string, unknown>).__promptCalls = [] as string[];
    let index = 0;
    (window as unknown as { LanguageModel: unknown }).LanguageModel = {
      availability: async () => 'available',
      create: async () => ({
        prompt: async (text: string) => {
          (window as unknown as { __promptCalls: string[] }).__promptCalls.push(text);
          const response = queuedResponses[Math.min(index, queuedResponses.length - 1)];
          index++;
          return response;
        },
        destroy: () => {},
      }),
    };
  }, responses);
}

export async function getPromptCalls(page: Page): Promise<string[]> {
  return page.evaluate(() => (window as unknown as { __promptCalls: string[] }).__promptCalls ?? []);
}
```

### Task 3: `ai-fetch-tool-loop.spec.ts` (item 2)

**Files:**
- Create: `e2e/tests/ai-fetch-tool-loop.spec.ts`

**Interfaces:**
- Consumes: `installLanguageModelStub` (Task 1, needs a **stateful/queued** stub — first response proposes `fetch_url`, second response is the final answer).

- [ ] **Step 1: Write the spec**

```ts
import { test, expect } from '../fixtures/page-tree';
import { installLanguageModelStub } from '../fixtures/ai';

test.describe('AI fetch_url tool loop', () => {
  test('a fetch_url tool call runs automatically and the model continues with the result', async ({
    page,
    pageTree,
  }) => {
    await page.route('**/api/fetch-url', (route) =>
      route.fulfill({
        status: 200,
        contentType: 'application/json',
        body: JSON.stringify({ content: 'Mocked fetched page content about widgets.' }),
      }),
    );

    await installLanguageModelStub(page, [
      JSON.stringify({
        message: 'Let me check that page.',
        action: { type: 'fetch_url', url: 'https://example.com/widgets' },
      }),
      JSON.stringify({ message: 'Based on the page, widgets cost $10.' }),
    ]);

    await page.goto(`/pages/${pageTree.rootGuid}`);
    await page.getByRole('button', { name: 'Open AI assistant' }).click();
    await page.getByRole('textbox', { name: /message|ask/i }).fill('What does example.com/widgets say?');
    await page.keyboard.press('Enter');

    // Grey tool row appears automatically -- no user action needed.
    await expect(page.locator('.msg.tool .tool-row')).toBeVisible();
    await expect(page.getByText('Based on the page, widgets cost $10.')).toBeVisible();
  });

  test('more than 3 fetch_url proposals in one turn are capped, not looped forever', async ({ page, pageTree }) => {
    await page.route('**/api/fetch-url', (route) =>
      route.fulfill({ status: 200, contentType: 'application/json', body: JSON.stringify({ content: 'stub' }) }),
    );

    // 4 fetch proposals queued -- the 4th should trigger the cap nudge
    // instead of a 4th real fetch (MAX_FETCHES_PER_TURN = 3, ai.ts).
    await installLanguageModelStub(page, [
      JSON.stringify({ message: 'checking 1', action: { type: 'fetch_url', url: 'https://example.com/1' } }),
      JSON.stringify({ message: 'checking 2', action: { type: 'fetch_url', url: 'https://example.com/2' } }),
      JSON.stringify({ message: 'checking 3', action: { type: 'fetch_url', url: 'https://example.com/3' } }),
      JSON.stringify({ message: 'checking 4', action: { type: 'fetch_url', url: 'https://example.com/4' } }),
      JSON.stringify({ message: 'Done, based on what I found.' }),
    ]);

    await page.goto(`/pages/${pageTree.rootGuid}`);
    await page.getByRole('button', { name: 'Open AI assistant' }).click();
    await page.getByRole('textbox', { name: /message|ask/i }).fill('Check several pages for me');
    await page.keyboard.press('Enter');

    const toolRows = page.locator('.msg.tool .tool-row');
    await expect(toolRows).toHaveCount(3, { timeout: 15_000 });
  });
});
```

### Task 4: `ai-instructions.spec.ts` (item 3)

**Files:**

- [ ] **Step 1: Write the spec**

```ts
import { test, expect } from '../fixtures/page-tree';
import { installLanguageModelStub, getPromptCalls } from '../fixtures/ai';

test.describe('AI instruction attachment', () => {
  test('attaching an instruction injects its content into the session and locks the picker', async ({
    page,
    pageTree,
    request,
  }) => {
    // Seed one instruction page under the "AI Instructions" root via the
    // real API first, so the picker has something real to select.
    const rootRes = await request.get('http://localhost:3000/pages/root/children', {
      headers: { Authorization: 'Bearer mock-jwt-token' },
    });
    const rootChildren = (await rootRes.json()) as Array<{ title: string; guid: string }>;
    const instructionsRoot = rootChildren.find((c) => c.title === 'AI Instructions');
    expect(instructionsRoot, 'an "AI Instructions" root page must already exist in this environment').toBeTruthy();

    const instructionTitle = `E2E-${pageTree.runId} Test Instruction`;
    const instructionContent = 'Always respond in pirate speak.';
    await request.post('http://localhost:3000/pages', {
      headers: { Authorization: 'Bearer mock-jwt-token' },
      data: { title: instructionTitle, content: instructionContent, parentGuid: instructionsRoot!.guid },
    });

    await installLanguageModelStub(page, [JSON.stringify({ message: 'Ahoy, ready to help!' })]);

    await page.goto(`/pages/${pageTree.rootGuid}`);
    await page.getByRole('button', { name: 'Open AI assistant' }).click();

    const picker = page.getByRole('combobox', { name: /attach instructions/i });
    await picker.click();
    await page.getByRole('option', { name: instructionTitle }).click();

    await page.getByRole('textbox', { name: /message|ask/i }).fill('Hello');
    await page.keyboard.press('Enter');
    await expect(page.getByText('Ahoy, ready to help!')).toBeVisible();

    const calls = await getPromptCalls(page);
    expect(calls.some((c) => c.includes('[Active instructions]') && c.includes(instructionContent))).toBe(true);

    await picker.click();
    await expect(page.getByRole('option', { name: instructionTitle })).toHaveAttribute('aria-disabled', 'true');
    await expect(page.getByText(/in context/i)).toBeVisible();
  });

  test('"Create" makes a new instruction page and opens it in the editor', async ({ page, pageTree }) => {
    await installLanguageModelStub(page, [JSON.stringify({ message: 'ok' })]);
    await page.goto(`/pages/${pageTree.rootGuid}`);
    await page.getByRole('button', { name: 'Open AI assistant' }).click();

    const picker = page.getByRole('combobox', { name: /attach instructions/i });
    await picker.click();
    const newTitle = `E2E-${pageTree.runId} Created Instruction`;
    await page.getByPlaceholder(/new instruction title/i).fill(newTitle);
    await page.getByRole('button', { name: /^create$/i }).click();

    await page.waitForURL(/\/pages\/.+\/edit/);
    await expect(page.locator('wiki-markdown-toolbar')).toBeVisible();
  });
});
```

- [ ] **Step 1: Write the spec**

```ts
import { test, expect } from '../fixtures/page-tree';
import { installLanguageModelStub } from '../fixtures/ai';

test.describe('AI transcript auto-scroll', () => {
  test('the transcript scrolls to the newest message as it arrives', async ({ page, pageTree }) => {
    const longReply = 'A long reply. '.repeat(200); // force real overflow
    await installLanguageModelStub(page, [JSON.stringify({ message: longReply })]);

    await page.goto(`/pages/${pageTree.rootGuid}`);
    await page.getByRole('button', { name: 'Open AI assistant' }).click();
    await page.getByRole('textbox', { name: /message|ask/i }).fill('Give me a long answer');
    await page.keyboard.press('Enter');

    const log = page.getByRole('log', { name: 'Conversation' });
    await expect(page.getByText(longReply.slice(0, 20))).toBeVisible();

    await expect
      .poll(async () => {
        return log.evaluate((el) => el.scrollHeight - el.clientHeight - el.scrollTop);
      })
      .toBeLessThan(20); // within a small tolerance of "scrolled to bottom"
  });

  test('scrolling up manually is not yanked back down by a new message', async ({ page, pageTree }) => {
    await installLanguageModelStub(page, [
      JSON.stringify({ message: 'first reply '.repeat(100) }),
      JSON.stringify({ message: 'second reply' }),
    ]);

    await page.goto(`/pages/${pageTree.rootGuid}`);
    await page.getByRole('button', { name: 'Open AI assistant' }).click();
    await page.getByRole('textbox', { name: /message|ask/i }).fill('one');
    await page.keyboard.press('Enter');
    await expect(page.getByText('first reply')).toBeVisible();

    const log = page.getByRole('log', { name: 'Conversation' });
    await log.evaluate((el) => { el.scrollTop = 0; });
    await page.waitForTimeout(100); // let the guard's own scroll-position read settle

    await page.getByRole('textbox', { name: /message|ask/i }).fill('two');
    await page.keyboard.press('Enter');
    await expect(page.getByText('second reply')).toBeVisible();

    const scrollTop = await log.evaluate((el) => el.scrollTop);
    expect(scrollTop).toBeLessThan(50); // stayed near the top, wasn't yanked to bottom
  });
});
```
