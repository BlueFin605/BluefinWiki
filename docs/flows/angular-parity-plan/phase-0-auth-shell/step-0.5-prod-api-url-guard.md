## Problem

`environment.production.ts` ships `apiBaseUrl: ''`, regenerated by
`scripts/build-env.mjs`. Nothing asserts at build or bootstrap time that the
value is non-empty and non-local. React's prod build throws if
`VITE_API_BASE_URL` is missing or points at localhost (unless explicitly
allowed).

## Target behaviour

- A **production** build fails fast if the resolved API base URL is:
  - empty / missing, or
  - `localhost` / `127.0.0.1` / `0.0.0.0` / a `.local` host,
  unless an explicit escape hatch is set (`ALLOW_LOCAL_API_URL=1` env var).
- The error names the offending value and the fix.

## Implementation notes

**Files:** `frontend/scripts/build-env.mjs` (primary). Optionally a
belt-and-braces runtime assert in app bootstrap guarded by
`environment.production`.

- Put the check in `build-env.mjs` right after it resolves the value it writes
  into `environment.production.ts`. `throw new Error(...)` with a clear message;
  a non-zero exit fails the CI build step and `npm run build:prod`.
- Match `bluefin-dev` posture: the SPA calls the API at
  `api.{spa-domain}` — a valid prod value looks like
  `https://api.bluefinwiki.bluefin605.com`. Reject `http://` in prod too.
- Keep dev/staging env generation unaffected.

## Tests first (TDD)

- `scripts/build-env.spec.mjs` (or a small node test): resolver throws on
  empty / `http://localhost:3000` / `https://foo.local`; passes on
  `https://api.bluefinwiki.bluefin605.com`; passes on a local value when
  `ALLOW_LOCAL_API_URL=1`.
- If the script has no test harness today, add a minimal one that imports the
  pure validation function (extract it so it is testable).

## Acceptance criteria

- [ ] `build-env.mjs` exports a pure `assertProdApiBaseUrl(value, env)` and
      calls it for production builds.
- [ ] Empty / local / `http:` values fail the prod build with a named error.
- [ ] `ALLOW_LOCAL_API_URL=1` escape hatch works.
- [ ] Dev/staging builds unaffected; tests cover all branches.

## Out of scope

- Changing how `apiBaseUrl` is sourced or the deploy pipeline that sets it.
